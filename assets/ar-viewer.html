📱 Comment utiliser l'AR

  • Ouvre ce fichier depuis Chrome sur Android
  • Choisis un modèle 3D dans la liste ou charge le tien (.glb)
  • Appuie sur le bouton "Placer dans le monde réel"
  • Pointe ta caméra vers le sol — l'objet se place automatiquement
  • Pinch pour redimensionner, glisse pour déplacer

📦 Où trouver des modèles 3D gratuits ?

  • poly.pizza — milliers de modèles gratuits en .glb
  • sketchfab.com → filtrer "downloadable" → exporter en .glb
  • market.pmnd.rs — modèles orientés Three.js
